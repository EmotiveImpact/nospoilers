Decision set — four complete versions of the same app

compare these

These four are directly comparable. Every version contains the same complete capability set from the current Watch app: Overview, Alerts, Sources, Releases, Timeline, Setup, source drill-down, Notifications, Policy, Team, Retention, Audit, Install health, Scan API tokens, private registries, coverage gates, and acknowledge → assign → resolve. Each also carries the same Trial admin, Solo, Member, Ended, and Empty switcher. Only the information architecture changes.

Accuracy key: the entities, gates, data fields, and actions map to current main. Routing, saved filters, charts, command palette, unified Sources, setup progress, and Desk / Settings chrome are proposed client presentation—not features being claimed as already shipped.
