A few things worth knowing

Questions, answered.

No. NoSpoilers complements repository checks by inspecting the release output and connected public surfaces your customers receive.

Start with a package or build archive, connect GitHub, or inspect a production website. Supported formats and checked scope are described in the documentation.

A scan checks a particular input at a point in time. Coverage connects sources so you can follow supported release events and exposure changes over time.

You can choose an input first. Sign in is required to start scanning and view your results. This page is an interactive example and does not upload or scan anything.

The proposed customer flow includes a five-day trial. Continued scanning and monitoring require an active plan after it ends.

It records a specific release identity, the checked scope and its result. It is not a guarantee that the entire application is secure or that unscanned environments are safe.

See the retention policy for upload handling, stored evidence and deletion rules. Review these details before uploading sensitive material.
