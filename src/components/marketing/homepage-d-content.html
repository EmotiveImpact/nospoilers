Does this replace Git scanning?
No. NoSpoilers complements repository checks by inspecting the release output and the connected public surfaces your customers receive.

    
What can I inspect?
Start with a package or build archive, connect GitHub, or inspect a production website. Supported formats and checked scope are described in the documentation.

    
What is the difference between a scan and coverage?
A scan checks a particular input at a point in time. Coverage connects sources so you can follow supported release events and exposure changes over time.

    
Do I need to sign in before scanning?
You can choose an input first. Sign in is required to start scanning and view your results. The examples on this page do not upload or scan anything.

    
How long is the trial?
Five days. Continued scanning and monitoring need an active plan after it ends.

    
Can I use it with my team?
Team workflows bring connected coverage, roles and release evidence into a shared workspace. Contact us to discuss larger rollouts or security review requirements.
